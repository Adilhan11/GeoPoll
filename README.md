# GeoPoll - Hava Kalitesi ve Konum Tabanlı Anket Uygulaması

## 📱 Proje Hakkında

GeoPoll, kullanıcıların bulundukları konumda hava kalitesi verilerini görüntüleyebilecekleri  modern bir mobil uygulamadır. Harita mühendisliği alanında geliştirilmiş olan bu uygulama, kullanıcı dostu arayüzü ve gelişmiş özellikleriyle öne çıkmaktadır.

## 🚀 Özellikler

- **Kirlilik Haritası**: Antalya bölgesindeki hava kalitesi verilerini  görüntüleme
- **Konum Bazlı Hizmetler**: Kullanıcının konumuna göre özelleştirilmiş bilgiler
- **GeoBot Asistanı**: Konum ve hava durumu bilgilerini sağlayan chatbot
- **Güvenli Kimlik Doğrulama**: Firebase authentication ile güvenli giriş sistemi
- **Responsive Tasarım**: Tüm mobil cihazlarda uyumlu çalışan modern arayüz

## 🛠 Teknolojik Altyapı

- **Frontend**: React Native, Expo
- **Backend**: Express.js, Node.js
- **Veritabanı**: PostgreSQL
- **Kimlik Doğrulama**: Firebase Authentication
- **Harita Servisleri**: React Native Maps
- **API Entegrasyonları**: OpenWeather API

## 💻 Kurulum

1. Projeyi klonlayın:
\`\`\`bash
git clone [repo-url]
\`\`\`

2. Bağımlılıkları yükleyin:
\`\`\`bash
npm install
\`\`\`

3. Gerekli ortam değişkenlerini ayarlayın:
   - Firebase yapılandırması
   - OpenWeather API anahtarı
   - PostgreSQL veritabanı bağlantısı

4. Uygulamayı başlatın:
\`\`\`bash
npm start
\`\`\`

## 🔒 Güvenlik

- Kullanıcı verileri Firebase Authentication ile güvenli bir şekilde saklanmaktadır
- API istekleri için rate limiting ve güvenlik önlemleri bulunmaktadır
- Hassas veriler için şifreleme kullanılmaktadır
